Danger zone — Factory reset

This action wipes the FlexEdgeAdmin deployment back to factory state. It is intended for cases where the Domain layout has drifted too far to clean up by hand, or when handing the box to a different operator.

What gets wiped
  • Every Tenant, API Key, and Domain row.
  • Every User row except Super Admin(s) — including yourself.
  • All DHCP scopes, reservations, deployments, credentials, and SSH-access rows.
  • All TLS certificates, deployments, and deployment logs.
  • All Engines data (scan history, sgInfo collections, terminal sessions).
  • All Change Queue entries + SMC object registry.
  • All Platform logs + legacy DHCP/TLS activity logs.
  • On-disk artifacts: sgInfo archives, scan log files, webhook bearer tokens.
  • Every in-process cache section (SMC reads, engines list, scope discovery).
What survives
  • Your Super Admin account ({{ super_admin_email }}) — so you don't get locked out.
  • Any other user flagged is_super_admin=True.
  • The encryption key file on disk (so existing backup ZIPs remain restorable).
  • Platform settings (log mode, retention, cache TTLs, feature toggles).
  • Azure AD config in .env (outside the DB — automatically untouched).
A backup ZIP of the current database + encryption key will be generated and downloaded to your browser BEFORE the reset executes. Store it safely — it's your only rollback path if you change your mind.
