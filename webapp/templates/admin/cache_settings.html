FlexEdgeAdmin caches SMC reads in two named tiers. Every cached view picks one of these tiers based on whether FlexEdge writes to that data class.

  • Loose refresh — for inventory data FlexEdge does not mutate (engine list, cluster detail, policy list, TLS engine settings). Default 24 h. The push runner auto-invalidates on writes anyway, and the drift detector hook (planned) will drop sections when out-of-band changes are detected — so even 24 h is rarely actually stale.
  • Quick refresh — for data FlexEdge does mutate via the queue (host / network / service / group / fqdn elements, policy rules, reservation Hosts). Default 1 h. Short enough that operator edits feel current.
