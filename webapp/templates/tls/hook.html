Certbot Renewal Hook

Legacy path since LE.3 (2026-05-29). Let's Encrypt certificates managed through /tls/letsencrypt are now renewed by FEA's own in-process scheduler (operator answer LE-Q1=A) — you don't need certbot's host-cron path for those any more. This page stays so existing operator-tracked certbot lineages (the pre-LE.1 flow, where you ran certbot certonly on the host yourself) keep working: the deploy hook below still POSTs /tls/api/renew so FEA can redeploy whatever the host-cron renewed.
If every cert on this deployment was issued via /tls/letsencrypt/new, you can stop installing this hook — FEA handles renewals end-to-end without it.
